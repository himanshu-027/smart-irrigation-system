# 🌱 Smart Irrigation System

## 1. Introduction

The Smart Irrigation System is an Arduino-based automatic irrigation
project designed to monitor soil moisture and control a water pump
according to the moisture level of the soil.

The system reduces unnecessary water usage by supplying water only when
the soil becomes dry.

---

## 2. Objectivez

The main objectives of this project are:

- To monitor soil moisture automatically.
- To control a water pump using a relay module.
- To display the moisture level on a 16×2 I2C LCD.
- To reduce unnecessary water consumption.
- To develop a simple and low-cost automatic irrigation system.

7. Hardware / Wiring

The Arduino UNO acts as the main controller.

The soil moisture sensor is connected to analog pin A0.
The relay module is connected to digital pin D8.
The 16×2 I2C LCD communicates with the Arduino through the I2C
interface using SDA and SCL.

The relay provides switching control for the DC water pump.

⚠️ The pump should be powered using a suitable external power supply.
Do not power a high-current pump directly from the Arduino 5V pin.

12. Results

The prototype successfully demonstrates automatic irrigation control.

The system:

Reads soil moisture values in real time.
Displays the moisture value on the LCD.
Turns the pump ON when the moisture reading is greater than 700.
Turns the pump OFF when the moisture reading is 700 or below.
Displays the pump status on the LCD.
Provides sensor readings through the Serial Monitor.

The threshold value can be modified in the Arduino program according to
the type of soil and sensor calibration.

13. Advantages
Automatic irrigation control.
Simple and low-cost implementation.
Real-time monitoring.
Easy to understand and modify.
Helps reduce unnecessary water usage.
Suitable for small-scale agricultural and gardening applications.
14. Limitations
The system uses a fixed moisture threshold.
Sensor readings may vary depending on soil type.
The basic prototype does not provide remote monitoring.
The system does not automatically detect water tank level.
Sensor calibration may be required for accurate operation.

16. Conclusion

The Smart Irrigation System successfully demonstrates how an Arduino,
soil moisture sensor, LCD, relay, and water pump can be combined to create
an automatic irrigation system.

The prototype continuously monitors soil moisture and controls the pump
according to the programmed threshold. This provides a simple approach
to automatic irrigation and can be further developed into an IoT-enabled
and intelligent agricultural system.
